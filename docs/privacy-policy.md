# ZeroZen 隐私政策

最后更新：2026-09-20 · 适用版本：0.6.0 及以上

## 一句话概括

ZeroZen 不收集、不上传、不出售任何个人数据。扩展没有后端服务器，所有规则匹配、统计与学习都在你的浏览器本地完成。

## 扩展会处理哪些数据

| 数据 | 用途 | 存放位置 | 是否离开设备 |
| --- | --- | --- | --- |
| 你访问页面的域名 | 匹配规则、按站点记录净化数量、按站点开关与档位 | 浏览器本地存储（`storage.local`） | 否 |
| 自定义规则、AI 待审条目、扫描结果 | 广告屏蔽 | 浏览器本地存储 | 否 |
| 每个站点的隐藏/拦截计数 | 控制台统计展示 | 浏览器本地存储 | 否 |
| 收藏夹网址（仅在你点击「读取收藏夹」时） | 批量扫描的站点来源 | 内存与本地存储 | 否 |
| 浏览记录中的域名与访问次数（仅在你启用「自主增强」时） | 挑选常访问站点做规则优化 | 内存，仅保留聚合结果 | 否 |
| 页面元素的结构化描述（仅在你启用「AI 识别」时） | 交给你自己配置的大模型接口判断是否为广告 | 不落盘（结果缓存 14 天） | **是**，发往你填写的地址 |
| 订阅列表地址 | 定期下载开源过滤规则 | 浏览器本地存储 | **是**，向你填写的列表地址发起下载请求 |

扩展不读取、不存储、不上传：网页正文、表单内容、密码、Cookie、网络请求体、页面截图。

## 两处会产生外部网络请求的功能

1. **AI 识别（默认关闭）**：只有你在控制台填入 OpenAI 兼容接口地址并启用后才会发起请求。发送内容仅限元素的标签名、class、id、尺寸、位置与不超过 140 字的短文本，短文本与属性可在设置中关闭。请求直接发往你填写的地址，不经过任何第三方中转，开发者无法看到内容。
2. **规则订阅（默认无订阅）**：只有你添加订阅源后，扩展才会按你设定的周期向该地址发起 GET 请求下载过滤列表。请求不携带 Cookie（`credentials: omit`），不附带任何浏览数据；对方服务器能看到的信息与你用浏览器直接打开该链接时一致。

「自主增强」模式只允许本地模型（Ollama / LM Studio 等回环地址），填写云端地址时不会启动。

## 权限说明

安装时申请：

| 权限 | 用途 |
| --- | --- |
| `storage` / `unlimitedStorage` | 保存规则、设置与统计 |
| `declarativeNetRequest` | 由浏览器按规则拦截广告请求；扩展只提供规则，看不到请求内容 |
| `scripting` | 向页面注入隐藏广告的 CSS |
| `tabs` / `webNavigation` | 知道当前标签页地址以套用对应站点的规则 |
| `contextMenus` | 右键菜单里的「选取元素屏蔽」 |
| `alarms` | 定时检查订阅更新 |
| `activeTab` | 快捷键触发时操作当前标签页 |
| `host_permissions: http/https` | 广告屏蔽必须能在所有站点生效；扩展不会因此读取页面内容并外传 |

按需申请（安装时不申请，用到才弹窗，可随时在控制台收回）：

| 权限 | 触发功能 | 用途 |
| --- | --- | --- |
| `bookmarks` | 批量扫描 | 只读取收藏夹里的网址与文件夹名，不修改收藏夹 |
| `history` | 自主增强 | 在本地按域名聚合最近 30 天访问次数 |
| `downloads` | 阅读保存 / 视频嗅探 / 图片发现 / 下载器 | 把文件写入下载目录下的 `ZeroZen/` 子目录 |
| `webRequest` | 拦截计数 / 视频嗅探 | 只观察请求地址用于计数和识别 m3u8/mpd，不读取请求内容 |

## 数据保留与删除

所有数据都在浏览器本地。控制台 →「统计与诊断」可以清除统计数据、恢复默认设置；卸载扩展会一并删除全部本地数据。扩展不使用 `storage.sync`，数据不会同步到你的浏览器账号。

## 儿童隐私

扩展不面向 13 岁以下儿童，也不收集任何可识别个人身份的信息。

## 变更

隐私政策变更会随扩展版本更新，并在仓库 `docs/privacy-policy.md` 中记录。

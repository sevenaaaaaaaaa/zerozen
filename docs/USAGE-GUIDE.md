# 零真 ZeroZen 使用指南

> 核心定位 · Features · 具体用例。写给刚开始用零真、想立刻还自己一个干净浏览器的人,
> 也是官网素材源之一。Chrome / Edge / Arc / Firefox / Safari,纯本地运行。

---

## 核心定位

打开一个资讯站,先看到的往往是弹窗、浮层和信息流里的「内容」;想下载个视频,又要在层层诱导按钮里找真链接。零真把这两件事一起解决:**规则引擎把广告和弹窗清干净,AI 识别补上规则覆盖不到的新花样,下载工具箱把视频完整存下来**。

它是一个纯本地扩展:没有服务器、没有账号,拦截由浏览器自带的 `declarativeNetRequest` 引擎完成,扩展本身看不到任何请求内容;权限按需索取,第一次用到才询问、随时收回。

零真是芭乐派矩阵里的**独立引流品**(Studio 层):不依赖矩阵任何产品、不要求注册、不引导转化,功能免费——它代表矩阵「本地优先、诚实边界」的产品观,好用与否,装上三分钟就能自己验证。

## Features(按你将真实用到的顺序)

### 1. 装上即净:41 规则包 · 7283 条规则
四层协同:网络层 `declarativeNetRequest` 拦截 + 外观层 CSS 隐藏/移除 + 弹窗守护(劫持无手势 `window.open`)+ 信息流空位自动回填。覆盖中 / 日 / 韩 / 俄 / 欧 / 东南亚 / 印度 / 拉美 / 港澳台站点:通用拦截、搜索/社交、视频/直播、资讯/电商、区域站点……分组全览见扩展控制台。装完打开常用网站直接见效。

### 2. 按站点调档:分组开关与白名单
41 个规则包按分组独立开关;私网 / NAS / 路由器后台 / 在线文档(飞书、腾讯文档、Notion……)默认不启用,管理后台与文档编辑零干扰。

### 3. 阅读模式与纯净浏览
一键提取正文,收束动画后进入无干扰阅读;正文深度净化只留语义结构,浅色/羊皮纸/深色/灰色四主题 + 字号调节;可存 Markdown 或带主题的独立 HTML,长文还能一键机器翻译(可译回原文)。一键隐藏导航 / 侧栏 / 评论,长文只留内容。

### 4. Alt+Z 点选即规则
选中页面元素直接生成隐藏 / 移除 / 放行规则;从 AI 结果与批量扫描自动学习选择器,多站点复现时自动通用化。

### 5. 规则订阅:10 个预设源自动更新
EasyList / EasyPrivacy / anti-AD / AdGuard / uBlock / CJX 等,条件请求自动更新、备用地址自动切换;Adblock / hosts / 纯域名 / JSON 四种格式通吃。

### 6. Alt+A AI 识别:补规则的盲区
遇到规则没见过的原生广告或假下载按钮,一键请出你自己填的 OpenAI 兼容接口(OpenAI / DeepSeek / 智谱 / 通义 / 硅基流动 / 本地 Ollama);只发送元素的结构化描述,不传网页正文、不截图、不传 Cookie。带缓存(同元素 14 天)与限额,结果先进「待审」。

### 7. 下载工具箱:视频从发现到落盘
视频嗅探(不点播放也能发现)→ 主播放列表可选画质 → m3u8 解密合并(AES-128)→ 分片级断点续传(IndexedDB 持久化)→ 按类型自动归档 `ZeroZen/`;下载中有实时进度卡片(分片/字节/速度/剩余时间),缓存面板随时查看与清理;防盗链站点自动带 Cookie 与 Referer 伪装,后台执行,关掉弹窗不中断。

## 具体用例(可直接照抄的实战路径)

### 用例 A · 日常浏览净化(所有人)
1. 加载扩展:Chrome 打开 `chrome://extensions` → 开「开发者模式」→「加载已解压的扩展程序」选 `dist/chrome`;Firefox 装 `dist/zerozen-firefox-0.8.1.xpi`;
2. 打开你常刷的资讯站,弹窗与信息流广告已经消失,空位被自动回填;
3. 个别站想看原始状态?点扩展图标进控制台,按分组关掉对应规则包或加白名单;
4. 顺手记住两个快捷键:`Alt+Z` 点选元素屏蔽、`Alt+A` AI 识别本页——后面两个用例全靠它们;
5. 遇到长文,一键进阅读模式。
**结果**:装完三分钟,浏览器从「广告里找内容」变回「内容就是内容」。

### 用例 B · AI 识别拦截新型广告(规则拦不住时)
1. 扩展控制台里找到 AI 识别设置,填入你的 OpenAI 兼容接口地址与 key(本地 Ollama 也行);
2. 打开有疑似广告的页面,按 `Alt+A` 发起识别;
3. 看「待审」列表:确认是真广告就采纳,误判就驳回;
4. 采纳的规则沉淀下来,同元素 14 天缓存,下次秒拦;
5. 不想用了?AI 识别的开关在控制台,关掉即刻停止发送任何请求。
**结果**:规则库没见过的新花样也能拦,且每一次识别你都是审批人。

### 用例 C · 点选即规则:亲手清理顽固元素(进阶用户)
1. 在目标元素上按 `Alt+Z`,点选它;
2. 选「隐藏」或「移除」,规则即时生效;
3. 在控制台里查看这条自定义规则,别的站点出现同类元素时它也会生效;
4. 冲突时优先级:自定义规则 > 内置包 > 订阅规则。
**结果**:任何漏网的元素,十秒内变成一条你拥有的规则。

### 用例 D · 把视频完整存下来(资料收集)
1. 打开有视频的页面,点扩展图标进下载工具箱,嗅探列表自动出现视频流(不用点播放);
2. 选 m3u8 流开始下载,AES-128 加密自动解密合并;
3. 中途关掉页面?重新打开工具箱,分片级断点续传接着来;
4. 下载完成,文件按类型归档在 `ZeroZen/` 目录;
5. 超过 2GB 的分段流,确认服务器支持 `Range` 请求即可多线程分段加速。
**结果**:视频从「在线看」变成「自己的文件」,大文件也不怕断。

## 常见问题

**会误伤正常页面吗?**
选择器做了词边界处理,不误伤正常类名;自定义规则优先级最高,随时可放行;内网与在线文档默认不启用。

**为什么有的广告还是会出现?**
快扫看不到 JS 动态插入的广告;YouTube 视频内广告用静音 + 快进 + 跳过组合策略,极少数直播 / 长广告可能有一瞬画面;遇反广告拦截墙自动回落档位(清单见 docs/compatibility.md)。

**AI 识别会泄露网页内容吗?**
只发送元素的结构化描述与页面地址标题,不上传正文、不截图、不传 Cookie;默认关闭,你开了、填了 key 才发请求,且直接发往你填写的地址。

**什么视频下载不了?**
SAMPLE-AES / DRM 加密无法下载;多线程分段需服务器支持 `Range`,上限 2GB;后台任务由工具箱标签页执行,关闭该页下载暂停(进度保留)。

**应用商店能装吗?**
Chrome Web Store 审核中;当前请按仓库说明加载 dist 产物。Safari 16.4 以下仅外观规则、无收藏夹接口,其余版本需本地构建转换。

**Safari 和 Chrome 版功能一样吗?**
核心净化规则一致;Safari 受浏览器接口限制,以上述差异为准,详见 docs/compatibility.md。

## 3. 自动回落档位

反广告拦截检测会随着拦截强度提高而出现，扩展采用两段式自动回落（可在控制台关闭）：

1. **第一次检测到反拦截墙**（多语言文案 + 覆盖视口的固定层）：
   - 该站点自动从「标准」回落到**兼容档**：只保留通用拦截与视频规则，去掉烦扰元素、长尾模板、站点特有规则和文案规则；
   - 页面右下角提示「检测到反广告拦截，已自动切换为兼容档」。
2. **回落成兼容后仍被拦截**（再次检测到墙）：
   - 自动**临时放行**该站点（默认 30 分钟，可在控制台调整）；
   - 到期后自动恢复原档位，不需要手动清理。

手动操作（弹窗里都有）：

- 档位：`兼容 / 标准 / 严格` 三键切换，只影响当前站点；
- 临时解除：一键放行当前站点 N 分钟，再点一次立即恢复；
- 屏蔽类型：网络拦截 / 外观隐藏 / 弹窗守护 / 烦扰元素 四个全局开关；
- 恢复到本站默认：清掉自动回落和手动覆盖。

## 4. 档位选择建议

- **标准**（默认）：绝大多数站点最优解，全部 35 个规则包生效。
- **兼容**：登录/支付/办公类站点、反拦截强的站点（Twitch、部分新闻订阅站），或你发现某个站点功能被误伤时。
- **严格**：只想尽快把广告清干净、能接受偶发站点功能异常的页面；会移除广告容器并强制解锁滚动。
- 遇到任何站点打不开或功能异常：弹窗里点「临时解除」，然后反馈给规则包作者补充例外。
